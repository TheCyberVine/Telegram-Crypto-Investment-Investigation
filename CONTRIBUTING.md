# Contributing

Thank you for your interest in contributing.

This repository documents a completed cybersecurity case study. Contributions are welcome if they improve the educational value, technical accuracy, or clarity of the investigation.

---

## Ways to Contribute

You can help by:

- Correcting factual inaccuracies
- Improving technical explanations
- Fixing grammar or formatting
- Suggesting additional OSINT methodologies
- Improving visual diagrams
- Reporting broken links

---

## Before Opening an Issue

Please ensure:

- The concern is supported by evidence.
- Duplicate issues do not already exist.
- Personal opinions are clearly identified as opinions.

---

## Pull Requests

Please:

- Keep changes focused.
- Explain why the change improves the repository.
- Cite reliable sources where applicable.
- Preserve the educational nature of the investigation.

---

## Evidence Policy

Do not upload:

- Personal information
- Private conversations without consent
- Unredacted screenshots
- Wallet seed phrases
- Credentials

All submitted evidence should be publicly obtainable or properly anonymized.

---

## Code of Conduct

By contributing, you agree to follow this repository's Code of Conduct.

Thank you for helping improve cybersecurity education.
